Conecte ao computador

Abra a IA no seu PC e copie o código que aparecer na tela.

Como preparar o PC?

Primeiro: abra o Qwen pelo llama-server no computador.

Depois: na pasta do AppSpace no Windows, abra um terminal e execute:

npm.cmd run ai:agent

Copie o código (token) mostrado no terminal e cole abaixo. Não compartilhe esse código.

No celular: esta versão usa USB com adb reverse tcp:8765 tcp:8765 configurado no PC. Conectar apenas pelo Wi-Fi ainda não é suportado.

A IA precisa estar aberta no Windows.
Endereço de conexão (avançado)

Use o endereço padrão, a menos que tenha mudado a porta do serviço Windows.

2

Escolha como a IA responde

Comece pelo modo equilibrado. Você pode mudar quando quiser.

O Qwen faz uma revisão extra para responder com mais cuidado. Pode demorar mais.

O botão ficará disponível depois que você conectar o PC no passo 1.

Mais opções (opcional)

Estas configurações não são necessárias para começar.

Essa opção é só uma preferência do perfil; o limite real é configurado no Qwen do PC.

Módulos selecionados: 0. Ativar uma opção no aplicativo não altera os pesos do Qwen.
